# gander-actions.github.io

Landing page for the [gander-actions](https://github.com/gander-actions) organization, published at <https://gander-actions.github.io/>.

Reusable GitHub Actions and workflows for CI/CD, built and maintained by gander.

## Development

The site is built by GitHub Pages with [Jekyll](https://jekyllrb.com/). Projects are listed in `_data/projects.yml`; add an entry there to show a new project on the page. Only public repositories belong on the page.

```sh
bundle install
bundle exec jekyll serve
```
